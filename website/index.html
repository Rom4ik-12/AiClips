MCP-интеграция

AiClips включает MCP-сервер, который позволяет AI-агентам управлять таймлайном. Подключите Claude Desktop и управляйте проектом голосом или текстом.

  • get_timeline — получить текущее состояние
  • add_clip — добавить клип
  • update_clip — изменить свойства
  • render_video — запустить рендер
Инструкция по настройке

Быстрый старт

1

Клонируйте репозиторий

git clone https://github.com/Rom4ik-12/AiClips.git
cd AiClips
2

Запустите бэкенд

cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
3

Запустите фронтенд

cd frontend
npm install
npm run dev
