# AiClips Frontend

React-приложение редактора видео для проекта AiClips.

## Скрипты

```bash
npm run dev      # Запуск dev-сервера
npm run build    # Production-сборка
npm run preview  # Просмотр production-сборки
npm run lint     # Проверка ESLint
```

## Конфигурация

API бэкенда настраивается в `src/api.js` (по умолчанию `http://localhost:8000`).
